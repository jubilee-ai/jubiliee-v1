Jubilee Callstack & Agent Flow

Post-refactor architecture. Single entry POST /api/chat → unified SSE vocabulary → one reducer.
All state keyed by experiment_id. Metadata in Postgres, artifacts in R2. LLM tokens streamed everywhere.

1 Full Callstack: Frontend → Backend → LangGraph

Every user interaction follows this stack. The branching point is chat() which routes to the orchestrator (tools + chat) or training graph (pipeline + HITL).

Agent lifecycle management

  • Creation: create_training_agent(checkpointer=MemorySaver()) inside generate_graph_sse_events
  • Storage: Agent + checkpointer stored in repository.put_simple_agent_store(thread_id, {...}) — in-memory dict keyed by thread
  • Resume: repository.get_simple_agent_store(thread_id) retrieves agent + checkpointer. Command(resume=decision) passed as stream input.
  • Thread binding: experiment.training_state.graph_thread_id persisted to DB so resume resolves server-side
  • Interrupt tracking: interrupt IDs saved via repository.save_interrupt_ids(thread_id, ids) — multi-interrupt resume maps each ID to the same decision
  • Final state: On pipeline completion, _graph_state_snapshot_values() extracts full state → save_training_context() + save_run_dataset_links()

6 Pre-Resolved Context & Step Skipping

How pre-resolved inputs flow

  • Frontend selects dataset → linked_datasets in request (key = file || id || name)
  • generate_graph_sse_events → resolve_linked_dataset(key): in-memory → filesystem → DB name → DB UUID → R2 download via storage_key
  • Resolved ref sets resolved_dataset_ref on initial state
  • model_preference → resolved_model_type when it's a specific family
  • Planner LLM prompt includes: "Dataset already loaded, do NOT plan data_collection"
  • _validate_plan() enforces: strips pre-resolved steps from plan + required set
  • Step node fast-path: checks state["resolved_dataset_ref"], returns immediately
agents/training/core/state.py → planner.py → data_collection.py / select_model.py

Dataset storage

  • Write: In-memory cache → R2 upload (datasets/{source_type}/{ref}.parquet) → Postgres row with storage_key in properties
  • Read: In-memory → Postgres lookup → R2 download → cache
  • Derived datasets: source_type="derived" — hidden from main picker by default
  • Catalog API: GET /api/datasets?include_derived=false — Postgres-only, no JSON fallback
tools/data-tools/utils.py → backend/catalog/repository.py

Model storage

  • Write: Postgres ModelVersion → R2 upload at storage_key
  • Read: In-memory _model_cache → Postgres lookup → R2 download to temp → joblib.load
  • Download: GET /api/trained-models/:name/download → presigned R2 URL
  • No local registry: registry.json + _load_registry() removed
tools/models-tools/training/model_storage.py → backend/shared/artifact_store.py

Deduplication: stream_step_key

  • Backend: _pipeline_emit_key() format: {len(plan_history)}:{plan_index}:{node_name}
  • After replan, plan_history grows → same step name gets a different key
